# 🍽️ Cravora – Food Ordering Web Application

Cravora is a full-stack food ordering web application built with **Python and Django**. It provides separate customer and admin workflows for restaurant browsing, menu management, cart handling, checkout, payments, and order tracking.

## 🚀 Live Demo

👉 **[Open Cravora Live](https://cravora-d8zz.onrender.com)**

> Razorpay is configured in **Test Mode** for demonstration purposes.

## ✨ Key Features

### 👤 Customer Features

- User registration and login
- Browse restaurants and menus
- Search restaurants
- Veg / Non-Veg menu filtering
- Add food items to cart
- Increase / decrease item quantities
- Remove individual items from cart
- Clear cart
- Automatic subtotal and delivery fee calculation
- Checkout and order summary
- Razorpay payment integration
- Order confirmation
- Order history
- Customer profile
- Logout

### 🛠️ Admin Features

- Admin login
- Admin dashboard
- Add restaurants
- Update restaurant details
- Delete restaurants
- Add menu items
- Update menu items
- Delete menu items
- Manage restaurant and menu information
